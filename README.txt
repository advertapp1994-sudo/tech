NuR HOME 3D MOBILE — V0.9
Android Studio: open this folder, sync Gradle, Build > Build APK(s).
GitHub: upload all files including .github to a repository, Actions > Build NuR HOME APK > Run workflow. Download artifact NuR-HOME-3D-APK and extract app-debug.apk.
Offline editor based on Windows V0.9. Native JSON save/open and print. Zoom buttons; pinch zoom not implemented. PDF album popup and CSV export inherited from desktop and not verified on Android. APK build and device testing not performed here.
